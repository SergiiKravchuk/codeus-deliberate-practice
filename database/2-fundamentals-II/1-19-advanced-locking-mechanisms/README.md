# 🧠 SQL Locks Practice

Цей репозиторій містить практичні завдання для тренування роботи з блокуваннями у PostgreSQL. Ви навчитеся використовувати різні типи блокувань для захисту даних від гонок, deadlock-ів та інших проблем конкурентного доступу.

---

## 📦 Структура проєкту

```
.
├── docker-compose.yml         # Піднімає БД та середовище для тестування
├── init.sql                   # Ініціалізація всіх таблиць і тестових даних
├── tasks/
│   └── task1.sql ... task8.sql# Ваші SQL-відповіді на задачі
├── tests/
│   └── all-tasks.test.js      # Jest-тести для автоматичної перевірки всіх задач
├── README.md                  # Цей файл
```

---

## 🚀 Як почати

1. **Встановіть Docker**  
   Якщо у вас ще не встановлено Docker, [завантажте та встановіть його](https://www.docker.com/products/docker-desktop/).

2. **Клонувати репозиторій**
   ```bash
   git clone <repo-url>
   cd database-locks-practice
   ```

3. **Підняти базу даних**
   ```bash
   docker compose up -d db
   ```

4. **Запустити тести**
   ```bash
   docker compose run --rm test-runner
   ```
   або, якщо ви працюєте локально з Node.js:
   ```bash
   npm install
   npm test
   ```

5. **Зупинити все**
   ```bash
   docker compose down -v
   ```

---

## 📝 Як виконувати завдання

1. Відкрийте відповідний файл у папці `tasks/` (наприклад, `task4.sql`).
2. Напишіть SQL-запит згідно умови задачі.
3. Збережіть файл.
4. Запустіть тести — вони автоматично перевірять вашу відповідь.
