# Database Sharding Deep Dive Theoretical Session

This module contains only a presentation for a deep dive into Database Sharding mechanisms, its benefits, challenges, and existing implementations and their comparison.
Also, the presentation covers an extension for PostgreSQL - Citus, which is one of the Database Sharding mechanism implementations. Its includes concepts, architecture and benchmark information.
